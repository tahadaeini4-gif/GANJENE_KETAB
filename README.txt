گنجینه کتاب - نسخه Offline First

محتویات بسته:
- index.html : نسخه اصلاح‌شده سایت
- sw.js : فایل Service Worker برای نگهداری فایل‌های برنامه در Cache
- manifest.webmanifest : مشخصات نصب برنامه به شکل PWA

نصب روی GitHub Pages:
1) از مخزن GitHub خود یک نسخه پشتیبان از فایل فعلی index.html بگیرید.
2) سه فایل این بسته را در همان پوشه‌ای قرار دهید که index.html فعلی قرار دارد.
3) فایل قبلی index.html را با index.html این بسته جایگزین کنید.
4) Commit و Push کنید و منتظر انتشار GitHub Pages بمانید.
5) هر دستگاهی که قرار است آفلاین کار کند باید حداقل یک بار با اینترنت سایت را باز کند و سپس یک بار صفحه را Refresh کند تا فایل‌های سایت در حافظه آفلاین مرورگر ذخیره شوند.
6) پس از آن می‌توان اینترنت را قطع کرد و سایت را از همان مرورگر/دستگاه باز کرد.

نکات مهم:
- داده‌های کتابخانه در IndexedDB همان مرورگر/دستگاه ذخیره می‌شوند و با بستن مرورگر از بین نمی‌روند.
- نسخه محلی در اولویت است و تغییرات پس از برقراری اینترنت به API فعلی Google Apps Script ارسال می‌شوند.
- اگر داده اولیه سرور برای اولین بار قابل دریافت نباشد، برنامه از ارسال نسخه خالی به سرور جلوگیری می‌کند تا اطلاعات قبلی ناخواسته بازنویسی نشوند.
- ذخیره محلی بین دستگاه‌ها مشترک نیست. همگام‌سازی ابری فعلی همچنان به Google Apps Script وابسته است.
- اگر چند دستگاه به‌صورت هم‌زمان یا آفلاین اطلاعات متفاوتی را تغییر دهند، سیستم فعلی تعارض‌ها را به‌صورت هوشمند ادغام نمی‌کند؛ برای کار چندکاربره واقعی به پایگاه داده و API با کنترل نسخه نیاز است.
- مرورگر یا کاربر می‌تواند داده‌های سایت را پاک کند؛ برای اطلاعات مهم، خروجی پشتیبان دوره‌ای نیز لازم است.
- در نخستین بازدید، یا پس از پاک‌کردن داده‌های مرورگر، دسترسی به اینترنت برای دریافت نسخه و اطلاعات اولیه ضروری است.
